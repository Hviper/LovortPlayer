# 🎨 Lovort 风格 UI/UX 设计规范与交互线框图

> 版本 v1.0 · 设计目标：极致克制、沉浸式深色质感（Lovort 风格）、微动效、手势驱动。

---

## 一、视觉设计语言与色彩规范

Lovort 的设计核心是 **极简、黑灰沉浸感、细腻的高斯模糊毛玻璃（Ultra Thin Material）**，避免杂乱的高饱和色彩，将所有视觉焦点留给视频内容本身。

### 1. 调色板 (Color Tokens)
- **Background 主背景**: `#0A0A0C` (近纯黑微冷调，OLED 省电且深邃)
- **Surface / Card 卡片层**: `rgba(255, 255, 255, 0.05)` 配合 `.ultraThinMaterial`
- **Border / Divider 边框与微光分割**: `rgba(255, 255, 255, 0.08)`，1px 极细描边
- **Accent 强调色**: `#F5F5F7` (极简白) 或 优雅极客荧光青 `#00F2FE` (仅用于状态激活点缀)
- **Text 主文字**: `#FFFFFF` (Primary), `rgba(255, 255, 255, 0.65)` (Secondary), `rgba(255, 255, 255, 0.35)` (Tertiary)

### 2.5 🔒 隐私保险箱解锁流 (Privacy Vault)
- **触发机制**:
  - 在媒体库主页顶部导航栏向下下拉持续 1.5 秒，或右上角双指长按。
- **验证交互**:
  - 自动触发 LocalAuthentication (Face ID / Touch ID)。
  - 若认证失败或取消，无任何提示（假装无此入口）。
  - 若输入假密码（Decoy PIN），展示一个伪造的空白媒体库。
  - 正确验证后，进入隐藏视频管理，并挂载隐藏沙盒加密卷。
