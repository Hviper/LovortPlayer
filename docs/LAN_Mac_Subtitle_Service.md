# 局域网 Mac 字幕服务方案

状态：规划中，当前 iPhone App 尚未连接 Mac 字幕服务。

## 目标与边界

让 iPhone 13 等设备把长视频的原文转写交给同一局域网内的 Mac。iPhone 继续负责视频播放、音轨选择、字幕缓存、翻译、编辑与导出。默认仍使用现有离线 WhisperKit；Mac 服务必须由用户显式启用。Mac 不接收翻译 API Key，也不处理第三方翻译。

只传用户选定的音轨，不传整部视频。私密视频需要先解锁并单次确认发送；Mac 只保留任务期间的加密临时音频，完成、取消或过期后清理。初期只支持 Apple Silicon Mac，并在连接时报告模型、语言、剩余空间及服务版本。

## 使用流程

1. Mac 启动独立服务，通过 Bonjour `_lovort-subtitles._tcp` 广播。iPhone 在设置里发现服务，展示设备名称与配对码；用户在两端确认后保存该设备的证书指纹。
2. 用户选择“此任务用 Mac 转写”。iPhone 检查模型、语言、Mac 空间与局域网连通性；首段优先发送约 20 秒音频，随后按现有四分钟时间轴发送剩余分片。
3. Mac 返回带片段序号、开始/结束时间、原文、模型标识的增量结果。iPhone 使用现有字幕检查点写入本地，再按用户选定的翻译服务翻译。原文先可看，译文稍后补齐。
4. 断线时保留手机上的已完成分片。用户可重连 Mac 续做，或切回手机离线转写；同一片段只由一个有效任务写入，旧连接的迟到结果必须被拒绝。

## 协议与安全

- Bonjour 只用于发现；数据使用 TLS。首次配对交换一次性短码并固定 Mac 证书指纹，后续连接验证指纹；不提供无认证的局域网 HTTP 接口。
- `GET /v1/capabilities` 返回协议版本、模型、可用空间和任务并发数。`POST /v1/jobs` 创建任务并返回任务 ID；音频分片上传带序号、大小与 SHA-256，支持按偏移续传。`GET /v1/jobs/{id}/events` 返回增量结果与进度，`DELETE /v1/jobs/{id}` 取消并清理。
- 不上传视频路径、片名、保险箱密钥或翻译凭据。任务 ID 为随机值，日志不记录台词或音频内容。Mac 限制输入大小、并发任务数和临时文件寿命。
- 结果包含源音频摘要、片段序号与时间基准。iPhone 验证摘要、时间范围和当前任务令牌后才接受，避免重连或切换引擎时写入旧结果。

## 实施顺序

1. 在 Mac 上做原文转写原型：沿用同版本 WhisperKit 模型，先用 10 分钟真实片源比较 Mac 与 iPhone 的总耗时、首条字幕时间和错误率。若传输加处理没有明显收益，不进入产品集成。
2. 完成配对、TLS、音频分片协议及断点续传，并做断线、重复分片、错误摘要、取消和多设备测试。
3. 接入 iPhone 任务中心与现有字幕缓存；加入私密视频确认、连接状态、Mac 忙碌提示和本机回退。
4. 用两小时影片在真实局域网测量端到端耗时、首条字幕时间、手机电量/发热和 Mac 临时空间；与 iPhone 13 本机 Large V3 Turbo 作同片对照。

首版不做远程互联网访问、不在 Mac 上翻译或保存媒体库，也不承诺后台无限时转写。iOS 后台时间限制和局域网变化需要通过可恢复任务处理。
